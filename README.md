## Featured Projects

### 🛡️ [AegisLand](https://suhaslord.github.io/portfolio/work/aegisland.html)
**UAV perception safety research · simulation-only**

External perception evidence you can inspect. Preregistered gates, frozen mixed holdouts, and a live research cockpit. Phase 10R improved average error but failed tail, availability, and calibration gates — frozen as-is for Phase 11.

- 43% → 1% unsafe episodes (Phase 6B synthetic, selective confidence)
- 84.2% → 2.4% unsafe rate (V3 redundant perception architecture)
- Phase 10R: mixed/failed result frozen at `e1d566f` without post-exposure tuning

**[Case Study](https://suhaslord.github.io/portfolio/work/aegisland.html)** · **[Research Cockpit](https://aegisland-research-cockpit.vercel.app/)** · **[GitHub](https://github.com/suhaslord/uav-safety-research)**

> **Note:** `safety_acceptance = false`. Simulation only. Not flight software.

### 🔇 [AbstainBench](https://suhaslord.github.io/portfolio/work/abstainbench.html)
**LLM calibrated abstention benchmark**

The same question as AegisLand, for language: when should a model answer, and when should it say it doesn't know? 30-question local-first benchmark with no API keys.

- Measures answer accuracy, abstention accuracy, hallucinations, false refusals
- Offline baseline + optional in-browser Llama 3.2 1B via WebGPU
- JSON and Markdown export for reproducibility

**[Live Demo](https://suhaslord.github.io/portfolio/demos/abstainbench/)** · **[GitHub](https://github.com/suhaslord/AbstainBench)**

### 🎨 [ECHO / FIELD](https://suhaslord.github.io/portfolio/work/echo-field.html)
**Generative instrument · canvas**

Voice, motion, and memory become a field that cannot be screenshotted into the same image twice. An exploration of ephemeral interaction design.
