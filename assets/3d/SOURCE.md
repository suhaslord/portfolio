# 3D scene sources

The Voyager spacecraft model is `Voyager Probe (A).glb` from NASA's public [NASA-3D-Resources](https://github.com/nasa/NASA-3D-Resources) collection. It includes the high-gain dish, body, instrument boom, braces, and separate material groups. The collection README describes these models as free and without copyright; this portfolio still credits NASA and links back to the source. The model is loaded progressively by `js/voyager.js` and is not used to claim NASA sponsorship or endorsement.

The Jupiter map is `Images and Textures/Jupiter/Jupiter.jpg` from the same collection. It is used as an illustrative material on a low-detail sphere. The page labels the camera sequence and trajectory as illustrative; measured Voyager results remain in the Voyager case study and its linked pull requests.

The static first-paint fallback also uses NASA/JPL-Caltech's archival [Voyager Test Model Configuration photograph (PIA21734)](https://science.nasa.gov/image-detail/pia21734/). It is a historical ground-test photograph, not a render of Suhas's software or a measured mission result. The astronomy card uses the author's public [HD 209458 b TESS transit-recovery output](https://github.com/suhaslord/citizen-science-astronomy-lab/blob/main/planet-hunters-tess/output/hd209458b_tess_transit.png); the adjacent AI card is an actual AbstainBench interface screenshot and is labeled as an adjacent artifact rather than a Seagulls capture.

NASA media and identifier usage follows the [NASA Images and Media Usage Guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/) and [NASA Brand Guidelines](https://www.nasa.gov/nasa-brand-center/brand-guidelines/). The NASA insignia is intentionally not reproduced on this third-party portfolio page.
