# Typeface

`dm-sans-variable.woff` is DM Sans, downloaded from the official Google Fonts source:

https://github.com/google/fonts/tree/main/ofl/dmsans

The variable TTF was losslessly repackaged as WOFF with fontTools. The complete SIL Open Font License and copyright notice are preserved in `DM-Sans-OFL.txt`.

Space Grotesk files are retained for older revisions; the current interface uses DM Sans.
