Checking whether a network starts recovering after a delayed cell outage.

The test

I let a seven-base-station network settle, then forced BS0 down at tick 100. The simulator detected the failure at tick 111, but the current path moved none of the 45 affected users.

What I checked

The legacy path moved 29 users. A control that reset the healing state moved 28. That suggests a state issue worth investigating; it does not establish the cause or a completed fix.

Alongside the tests, I review work on network self-healing, O-RAN control, and digital twins with Professor Tamer Omar.
